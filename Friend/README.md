# Friend

A place for daily conversation with your Cursor friend agent — separate from the game/repo work.

## How to talk to the friend

1. Open this folder (or a file under `Friend/`) in Cursor.
2. Start Agent chat, or invoke the custom agent with `/friend`.
3. Talk normally — vent, ask questions, brainstorm, hang out.

## What this agent does differently

- Answers quickly, but **checks facts** before treating them as true.
- Prefers “I don’t know / let me verify” over a confident wrong answer.
- If it was wrong, it owns it and corrects with verified info — it won’t just agree after you catch it.

## Optional daily notes

If you want a written log, ask the friend to save something under `conversations/` as `YYYY-MM-DD.md`.
